# Novira Customer Dashboard Prototype

Static GitHub Pages prototype for the Novira customer dashboard screens.

## Live Prototype

https://mohammad-ashaduzzaman.github.io/novira-customer-dashboard/

## Pages

- `index.html` - dashboard
- `trackers.html` and `tracker-details.html`
- `shipments.html` and `shipment-details.html`
- `fleets.html`
- `drivers.html`
- `alerts.html`
- `notifications.html`
- `widgets.html`
- `reports.html`
- `subscriptions.html`
- `support-tickets.html` and `support-ticket-details.html`

The HTML screens are self-contained. `prototype-links.js` adds click behavior for the sidebar, support/help controls, subscription plan controls, notification badge, list/detail navigation, and back buttons.
